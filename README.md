## 本次修正：股息率不能把“每10股金额”当“每股金额”

### 数据和单位

- 来源：东方财富 `RPT_SHAREBONUS_DET` 分红方案接口。`PRETAX_BONUS_RMB` 的单位是 **元/10股**；工具首先计算 **税前每股股息 = PRETAX_BONUS_RMB / 10**。
- `PLAN_NOTICE_DATE`（或可用的公告日期字段）作为公开宣告日，`REPORT_DATE` 用于区分年报/非年报。**不能拿除息日当公告日**：已经公告但尚未除息的分红应参与 RLY。
- 若方案文本存在 `10派X元`，程序会与数值字段逐项核对；冲突则跳过，不自动编造。
- 同一报告期的重复预案、实施记录只算一次；若同一期存在不同金额、无法确认更正，返回缺失并提示核对公告。
- 除息/分红公告可能包含送股转增，程序尝试按源侧股份变动将历史每股股息折算到观察时点；若外部接口字段欠缺，**历史折算不保证与原图作者完全一致**。

### RLY 的计算口径（参照用户提供的图片）

1. 找最近**已公告**的年度末期分红（报告期 `12-31`）。
2. 找已公告的年中分红（非 `12-31` 的报告期，如季度/半年报），按有效方案汇总；同一报告期不会多算。
3. 如本年中期仍未公告，沿用上期已公告的中期记录，并在页面明显标记 **「中期待定；沿用上期」**；一旦本年明确不分配，停止沿用。这样是观察口径，不代表本期分红已获确认。
4. `RLY (%) = (末期每股现金分红 + 中期每股现金分红) ÷ 当前未复权股价 × 100`。
5. 每只股票在**「分红方案与RLY计算明细」**里展示：报告期、公告日、原始「10派X元」、转换后的每股股息、是否进行送转折算、状态及原始核验入口。

**举例（仅核对公式，非当前真实行情）：** 若每10股派30元，每股现金股息3元，股价38.52元，RLY股息率=3/38.52×100%=**7.79%**。

### 股息率分位

- 使用过去约 10 年的**未复权周线收盘价**作为分母。对每周历史观察日，**仅选择截至当时已公告**的分红方案，重建该周的 RLY，计算百分位。不能使用后复权股价作为现金股息率分母；后复权只用于 BOLL。
- 按 `历史RLY <= 当前RLY 的有效样本数 ÷ 总有效样本数` 计算历史百分位。少于 100 个有效历史周样本时显示 `—`，不会靠填零补足样本。
- 上游的历史分红方案可能经历事后更正，历史送转可能数据不完整：这一分位是**同口径估算**，可能与原图作者按完整历史公告快照算出的结果不同。源码/API 返回样本数、覆盖日期和来源，便于核验。
- 原图还列出“首次中期分红过渡期折算”“陈旧档位失效”等定制修正；因缺少作者的可执行规则和完整历史公告快照，**本工具未宣称完全复刻这两项特殊修正**。若接口无法确认公告日或金额则显示缺失。

## BOLL：严格要求后复权 HFQ

- 腾讯财经获取日、周、月三套原生后复权 K 线，接口参数 `hfq`。如果没有 `hfqday/hfqweek/hfqmonth` 字段，不能擅自用未复权或前复权代替。
- **BOLL(20, 2)**：中轨 `SMA(CLOSE_HFQ, 20)`，标准差使用总体标准差 `ddof=0`，上轨 `MID+2σ`，下轨 `MID−2σ`。
- `上`（紫红）：价格 ≥ 上轨；`中上`（琥珀）：中轨 +1σ < 价格 < 上轨；`中`（灰蓝）：中轨 ±1σ；`中下`（浅绿）：下轨 < 价格 < 中轨 −1σ；`下`（深绿）：价格 ≤ 下轨。
- **低位共振**：周线和月线均为 `中` 或 `中下`，不使用日线，`下` 不算共振。
- 点击 **「刷新HFQ BOLL」** 可单独获取一个股票的 HFQ 价、BOLL 上轨/中轨/下轨四条价格曲线和实际计算值。

## 数据源、实时性与限制

- 参考开源项目 [a-stock-data](https://github.com/simonlin1212/a-stock-data) 中的公共接口用法，独立实现：腾讯财经报价、后复权 K 线、东方财富分红、 新浪财经报表、巨潮资讯原始公告。
- **互联网请求直接在你本机发出**：公开接口可能限流、空返回或字段改变。数据无法拉取会显示 `—` 或错误，不会使用示意图数据冒充行情。
- 行情“实时”指联网请求可返回的腾讯最新快照，不保证交易所毫秒级实时或行情授权等级。部分股票可能停牌/延迟。
- 目前没有内置商业版第三方 API Key，也没有自动对外部署。部署给外部客户或收费前需核对金融行情/公告数据授权及稳定性。
- 该项目采用公布的原始价格与股息数据用于研究观察，不构成投资意见。

## 源码结构和接口

- `engine.py`：分红公告正规化、RLY/历史分位、腾讯 HFQ K 线、BOLL、最新公告、财报指标。
- `app.py`：FastAPI 服务，批量刷新、缓存、单股详情与 CSV 导出。
- `static/`：UI 和原生 Canvas BOLL 上/中/下轨与 HFQ 收盘线。
- `tests/`：包含五档边界、公告去重、每10股单位、时间穿越、待定沿用、送转折算的测试。
- `/api/stocks`：33 只数据；`/api/stock/{代码}`：单股详情（含 RLY 审计明细）；`/api/stock/{代码}/dividends`：公开分红记录；`/api/stock/{代码}/boll`：单股 HFQ 三周期 BOLL；`/api/stock/{代码}/financials`：财报指标和公告入口；`/api/export.csv`：导出；`/docs`：接口文档。
